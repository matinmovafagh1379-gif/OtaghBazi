# Children's Playroom 🎨🧸

A playful and child-friendly interior design project created for a **Child Psychologist's Playroom**.

## 🎯 About the Project

This project focuses on designing a warm, safe, and engaging playroom environment for children visiting a child psychologist.

The space is designed to encourage **play, creativity, emotional expression, interaction, and a sense of comfort and safety** during therapy sessions.

## ✨ Design Goals

* Child-friendly and welcoming environment
* Safe and comfortable play area
* Spaces that encourage creativity and imagination
* Appropriate environment for psychological sessions
* Functional organization of toys and activities
* Warm and playful visual identity

## 🛠️ Project Focus

* Interior & Space Design
* Child-Friendly Environment
* Playroom Design
* User Experience
* Visual & Functional Design
